## Open

Owner-reported 2026-07-11, root-caused against code on 2026-07-11:

- [ ] **System prompt: master prompt + persona + memories are loaded then DISCARDED** — `luna-soul.cjs:310-325`: the config template (`config/luna-prompt-config.json`) has no `{{masterPrompt}}`/`{{personaContent}}`/`{{memoryContext}}` placeholders, so `LUNA_MASTER_PROMPT.md` (full tools table + exact JSON examples) never reaches the model. The config prompt itself does contain exact JSON examples for the first message, but follow-up/toolLoop templates (`luna-soul.cjs:3766-3784`) have NO JSON examples — model invents formats mid-conversation. (owner report + confirmed)
- [ ] **Tool cards render only partially in the web UI** — 4 confirmed causes: (1) backend dedup `luna-chat-routes.js:498-503` drops repeated `action_*` events (key lacks params/instanceId — 2nd call of same tool in a turn never reaches SSE); (2) `toolInstanceId` emitted by soul but dropped in transport (`luna-chat-routes.js:506-517, 655-676`); (3) `id: 'ev-' + Date.now()` collisions in the same ms; (4) failed/timed-out tools never get `action_end` → card stuck "running" forever (frontend TOOL_TIMEOUT_MS is dead code). (owner report + confirmed)
- [ ] **Duplicated/triplicated text during streaming** — 2 independent confirmed causes: (a) frontend append bug `ChatArea.svelte:117-136`: buffer never cleared on append path → quadratic re-append (settles on `done` forceText replace); (b) bridge: 3 concurrent text producers (extension, DOM poll, ultra-light observer) feeding ONE shared `lastResponse` cursor with `slice(length)` diff (`kimi-bridge.cjs:7532-7664`), plus parent+child selector duplication in `luna-extension/injected.js:34` and `kimi-dom-observer.js:17`. No soul→bridge handshake exists. (owner report + confirmed)
- [ ] **Luna stops responding randomly** — 9 confirmed silent-exit paths; main ones: empty bridge response treated as CHAT with `done` and empty string (`luna-soul.cjs:2654-2658` + `kimi-bridge.cjs:7806`); `context_limit`/cancel returns without `done` (`:2524`, `:2588`); bridge retry exhaustion falls through without error (`:2389`); `_waitPromisesWithDrain` infinite poll (`:3958-3977`); dedup-cache ping-pong loop (`:1631-1651` + `MAX_LOOPS = MAX_SAFE_INTEGER :2365`). (owner report + confirmed)
- [ ] **Auto-continue on pure `{"response"}`** — simple case stops correctly (`luna-soul.cjs:2669-2670, 2709-2712`), but real triggers confirmed: DOM poller scans response text for tool JSON ANYWHERE (`kimi-bridge.cjs:7786-7799`) → a response that QUOTES a tool example gets executed for real and the loop continues; META/SUGGEST/LOAD_SKILL/UPDATE_MEMORY modes never set `output` (`luna-soul.cjs:3528-3547`) → fall into `[CHECK]` auto-continue (`:2792-2799`). (owner report + confirmed)
- [ ] **Telegram persona path broken** — `luna-soul.cjs:4991` builds persona path with duplicated segments; `fs.existsSync` fails silently → empty persona fallback. (found during docs work 2026-07-11)
- [ ] **Tool guard schema registry desync** — `luna-tool-guard.cjs:142-198` only has schemas for ~11 tools; `validateToolCall` THROWS for all others (~110 tools incl. all dashboard tools) → in `luna-cli` sessions they fail schema validation; in web/Telegram sessions the guard is null (workspace `luna-cli` never matches `options.userId`, `luna-soul.cjs:1687-1693`) → ZERO validation/timeout/idempotency.
